# 기획: 마케팅 연간 현황 보관 + 연간 비교 분석 (2026-10-20)

## 1. 목적
- 2023~2026.4월(CRM 이전) 마케팅 현황표(구글 시트, 연도별 파일)를 CRM 안에 보관한다.
- 연도·월 단위로 광고비 / 가입 / 문의 / 도입을 나란히 비교한다. 2026.5월 이후는 CRM 데이터(광고성과·파이프라인)로 이어 붙여 같은 표에서 본다.

## 2. 원본 구조 (2025 파일 기준, 2026도 같음)
| 시트 | 내용 |
|---|---|
| `N년 전체` | 월별 요약 12행 + 분기·반기·총계. 열: 광고비(구글/메타(26년은 기타)/네이버/실 집행비/증감율), 가입사(수/증감율), 문의사(유료광고/바이럴/수/증감율), 도입사(수/증감율), 매출액·매출 대비 광고비 비율(25·24·23년 매출 비교), 전년 요약 메모 |
| `01월`~`12월` | 월 상세. 상단: 월간 예산(메타/영상/네이버/구글/콘텐츠)·진행·잔여, 소진율, 전환율. 본문: 광고유형(SNS/검색/콘텐츠) × 채널(메타/유튜브/네이버/구글/언론/검색/대표전화/해피톡+상담신청/블로그) × 유형(캠페인명) 별 비용·노출·클릭·CTR·CPM·가입·문의·도입 |

- 2026 파일은 1~4월만 값이 있고 5월~는 `#N/A` (CRM 전환).
- 2023·2024 링크는 비공개(열람 불가, 401). 공개로 바꾸거나 xlsx 로 내려받아 공유 필요.
- 2025 메모 행에 24년 요약(광고비 46,364,904 / 가입 723 / 문의 581 / 도입 62)이 있어 24년 파일 구조는 같을 것으로 보임.

## 3. 저장 구조 (신규 테이블 2개)
### `marketing_monthly_history` — 월 요약 (연도×월 1행)
year, month, cost_google, cost_meta, cost_naver, cost_other(팀부스터 등), cost_total(실 집행비), budget_total, signups, inquiries_paid, inquiries_viral, inquiries, adoptions, revenue(선택), source('sheet'|'crm'), notes
- 원본의 증감율·분기·반기·총계는 저장하지 않고 화면에서 계산 (원본 수식이 `#VALUE!` 인 곳이 있어 재계산이 안전).

### `marketing_monthly_channel_history` — 월 상세 (연도×월×유형×채널×캠페인)
year, month, ad_type(SNS/검색/콘텐츠), channel(메타/유튜브/네이버/구글/언론/검색/대표전화/해피톡/블로그…), campaign(유형 열, 없으면 null), cost, impressions, clicks, signups, inquiries, adoptions
- 합계 행(SNS 합계, 네이버 합계, 합계 등)은 저장하지 않음. 비어 있는 행(비용·노출·클릭·전환 모두 0)도 제외.

### 2026.5월~ : 저장하지 않고 CRM 에서 계산
- 광고비·노출·클릭: `ad_performance` (채널별 합)
- 문의·도입: `pipeline_leads` (문의일·도입월 기준) — 광고성과의 수동 문의 수와 어느 쪽을 쓸지 확인 필요
- 가입사: `ad_performance.signups` (현재 거의 입력 안 됨 → 2026.5~ 가입은 공란 가능성)

## 4. 화면: 마케팅 > 연간 비교 (`/marketing/history`)
1. **연도 비교 KPI** — 연도별 카드: 광고비, 문의, 도입, 가입, 문의당 광고비(CPL), 도입당 광고비, 문의→도입 전환율. 전년 대비 증감.
2. **월별 추이 차트** — 지표 선택(광고비/문의/도입/가입/CPL), 연도별 선을 겹쳐 그림 (1~12월 X축). 2026은 1~4 시트 + 5~ CRM.
3. **월별 표** — 선택 연도 12행 + 분기·연 합계. 전월 대비·전년 동월 대비 % 를 화면에서 계산.
4. **채널별 비용 비중** — 연도별 구글/네이버/메타/기타 스택 바. 월 상세가 있는 연도는 캠페인(유형)별 표도.
5. **콘텐츠·오가닉 문의 경로** — 검색/대표전화/해피톡/블로그 월별 문의·도입 (25·26 월 시트 '콘텐츠' 구간).
6. **업로드** — 연도별 xlsx 를 올리면 `N년 전체` + 월 시트를 읽어 그 연도 데이터를 교체. 결과(행 수·합계)를 보여주고 원본 합계와 대조.
- 네비게이션: 마케팅 ▸ 연간 비교. 매출액은 포함 여부 확인 후 결정 (기본: 광고비 대비 비율만 표시, 매출 숫자 자체는 재무 화면 담당).

## 5. 작업 단계
1. 테이블 2개 (migration 020) + xlsx 파서 + 업로드 API — 2025·2026 파일로 검증 (연 합계: 25년 광고비 15,172,290 / 가입 530 / 문의 550 / 도입 80)
2. 화면 1~4 (KPI·추이·월별 표·채널 비중)
3. 2026.5월~ CRM 데이터 이어 붙이기 (문의·도입 기준 확정 후)
4. 2023·2024 파일 받아서 적재, 화면 5(콘텐츠 경로)
5. DEV_LOG · 메모리 반영
