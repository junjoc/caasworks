카스웍스 CRM 디자인 정의

CRM 화면 디자인의 지금 정해진 것만 둔다. 맨 위 전역(모든 화면 공통) → 메뉴별 화면(CRM 메뉴 순서) → 기록. 지난 안은 지우고, 왜 골랐는지는 결정 기록에만 남긴다. 숫자는 2026-10-21 CRM 실제 데이터.

지금 정해진 것 — 한눈에 (2026-10-21 저녁 기준)

  1. 틀: 사이드바 200 · 헤더 48(화면 제목은 여기만) · 본문 좌우 20 위 16 아래 64(피드백 버튼 자리) · 흰 바탕 · 그림자는 떠 있는 것(드로어·메뉴·선택 바)만
  2. 화면 문법 v2: 화면 유형(목록 · 집계 · 추이 · 상세 · 드로어 · 보드 · 대시보드) × 부품 10 × 기준값 7(글자 12 이상 · 간격 · 모서리 · 선 · 색 · 경과 · 기준 한 줄). 모든 화면을 이것만으로 — ★ 화면 문법 v2
  3. 화면 머리: 툴바 40(왼쪽 탭·필터 / 오른쪽 보기 전환 → 기간 → 보조 → ⓘ → 주 동작) → 숫자줄 64(목록·집계·대시보드만, 최대 5칸) → 표. 상세는 이름줄 → 단계 줄 → 속성 줄
  4. 색: 13색만(10/21 미납 due 추가). 단계 = 신규 빨강 · 진행 파랑 · 예정 주황 · 도입완료 초록 · 이탈 회색(채운 칩, 최소 64). 미납·연체 = 진한 빨강 #B4233A. 유입 분류는 회색 점(상태색 쓰지 않음). 대비를 높인 B·C안은 색상표로 보관
  5. 표: 머리 가운데 · 숫자 오른쪽 · 날짜·상태 가운데 · 글 왼쪽 · 모든 열 연한 세로선 · 합계 줄 맨 위 고정 · 집계 표는 열 비율 고정 · 행 클릭 = 480 드로어 · 선택하면 화면 아래 선택 바
  6. 상세 · 드로어: 상세 = 단계 줄 + 속성 줄 5칸(누르면 그 자리에서) + 2:1(기록·날짜별 타임라인 / 카드, 값 있는 칸만). 드로어 = 상세 축소판(얇은 단계 줄 + 속성 칩). 폭은 480 · 60vw 두 가지
  7. 기록: 드로어·상세가 같은 기록 칸(유형 · 내용 · 다음 액션 · 언제). 다음 액션·단계·담당·칸 수정도 타임라인에. 나중에 올린 회의록은 실제 날에, 기록한 날은 꼬리표로
  8. 경과 표기: +n일(당일 오늘) · n일 남음 · 내일 · n일 지남 · n일 전. D+n · n일째 쓰지 않음
  9. 단계 순서: 신규리드 → 컨텍 → 예정 → 제안 → 미팅 → 도입직전 → 도입완료 (+ 이탈). 기록으로 단계 자동 이동은 앞으로만, 예정·도입완료는 사람이
  10. 속도: 화면 한 번에 요청 1개(서버 API) · 본 화면은 메모리에서 바로 · 행에 마우스 올리면 미리 읽기 · 열어 둔 동안 4분마다 서버 깨우기
  11. 데이터 기준: 유입 분류 11 + 미분류 (리드·GA 공통)
  12. 일하는 방식: 요청은 안 제시 → 합의 → 반영, 반영 뒤 이 문서와 결정 기록 갱신
