레이아웃 정의 v1 — 화면 유형 5가지

디자인 정의 v1(색·글자·버튼·표)은 그대로 두고, 그 부품을 어디에 얼마 크기로 놓는지와 데이터를 어떤 순서로 배열하고 몇 번에 불러오는지를 정한다. 시안 5장은 전부 CRM 의 오늘(2026-10-21) 실제 데이터다. 파란 라벨은 치수 표시이며 실제 화면에는 없다.

엔조가 먼저 정한 것 — 아니면 말해줘

  1. 틀은 하나. 사이드바 200(1,024px 이하 56 아이콘) · 헤더 48 · 본문 좌우 20 위 16 · 본문 최대 1,400(목록·집계·대시보드) / 960(상세) / 드로어 480(입력·목록 상세) · 60vw(집계 드릴다운)
  2. 표는 틀을 채운다. 열 폭은 내용 기준이되 남는 폭은 첫 열(회사명)이 흡수. 목록 표는 남은 화면 높이를 전부 쓰고 그 안에서 스크롤, 집계 표는 표마다 높이를 정한다(월별 = 12줄)
  3. 목록은 50행씩 서버에서. 1,214행을 한 번에 내리지 않는다. 검색·필터·정렬도 서버. 보드뷰만 예외(단계별 전체)
  4. 상세는 2:1. 왼쪽 주 내용(차트·표), 오른쪽 보조(청구·타임라인). 1,024 이하 한 열
  5. 대시보드는 자유 드래그를 뺀다. 역할 프리셋 3개 + 위젯 켜고 끄기만. 위젯은 숫자·목록 5줄·추이 3종으로 제한 → react-grid-layout 제거, 코드와 로딩이 같이 준다
  6. 입력은 드로어. 목록 위에 480 드로어로 열고 저장하면 목록 맨 위에 들어간다. 전체 페이지는 견적서뿐
  7. 요청 수 상한. 화면 열릴 때 목록 2 · 집계 1 · 상세 1(+드로어 1) · 입력 0(선택지는 전역 캐시) · 대시보드 1. 사용자·역할·선택지는 앱에서 한 번만

1. 목록 (파이프라인 리스트 · 전체 고객 · 청구서 · 티켓 …)

위에서 아래로 제목줄 56 → 툴바 40 → 표(남은 높이 전부) → 페이지줄 36. 행을 누르면 오른쪽 480 드로어, 목록은 그대로. 요약 숫자는 제목 옆 한 줄.

배치 수치

  • 제목줄 56: 제목 18/600 + 숫자 한 줄 12.5 · 오른쪽 동작 ≤ 2(주 동작 1)
  • 툴바 40: 탭 pill │ 검색 220 │ 셀렉트 ≤ 3 │ 체크. 넘치면 "필터" 버튼 하나로 접음
  • 표: 머리 34 고정, 행 36, 첫 열 고정, 짝수 줄 줄무늬, 남은 높이 안에서 세로 스크롤
  • 페이지줄 36: "1–50 / 1,214" + ‹ ›
  • 드로어 480: 머리(이름·상태·메타) → 요약 kv → 활동 → 메모 → 하단 바 48(위험 동작은 왼쪽 끝)

데이터 배열

  • 열 순서 고정: 식별(회사명) → 상태 → 분류(채널·발주·담당) → 날짜 → 우선·태그 → 다음 액션
  • 폭: 회사명 ≥ 200(남는 폭 흡수) · 상태 96 · 담당 56 · 날짜 100 · 금액 120 · 건수 64
  • 정렬 기본 최신순(유입일). 머리 클릭 정렬, 활성 열만 화살표
  • 긴 글(문의·다음 액션)은 한 줄 말줄임 + 툴팁. 태그는 3개까지 + "+n"
  • 빈 값은 — (회색). 0 은 0

불러오기

  • 열릴 때 2회: GET /api/leads?page=1&size=50&…(행 + 총 건수) · 탭별 건수 1회
  • 검색·필터·정렬·페이지 = 같은 API 다시 (300ms 디바운스). 전체 행 내려받기 없음
  • 드로어 열 때 1회: 그 행의 활동·메모
  • 저장 후: 그 행만 갱신(낙관적), 실패 시 되돌리고 토스트
  • 스켈레톤은 0.3초 넘을 때만 표 영역에

5. 대시보드

제목줄 56 → 숫자줄 64 → 12열 격자 위젯. 위젯은 3종(숫자·목록 5줄·추이)뿐이고 역할 프리셋으로 배치가 정해진다. 자유 드래그·리사이즈는 뺀다.

배치 수치

  • 숫자줄 64: 5개(역할별 다름). 값 18 + 보조(전월·비율) 11.5
  • 12열 격자, 간격 16. 추이 위젯 8열(높이 240), 목록·분포 위젯 4열(높이 240)
  • 위젯 = 제목 14/500 + 보조 설명 12 회색 + 내용. 테두리 1px, 바탕 없음
  • 한 화면(1,280×760)에 숫자줄 + 위젯 2줄이 들어오게. 세 번째 줄부터 스크롤
  • 프리셋 3: 경영진 · 세일즈 · 마케팅. 설정에서 위젯 켜고 끄기(순서는 고정)

데이터 배열

  • 숫자줄 왼쪽부터 유입 → 매출 → 도입 → 미납 → 할 일 (돈 들어오는 순서)
  • 목록 위젯은 5줄 고정, "더 보기" 링크로 해당 목록 화면
  • 추이 위젯은 올해 12개월, 이번 달은 강조색, 미래 달은 계약 기준 표시
  • 분포는 단계 순서(신규→이탈) 고정, 색은 단계 색
  • 모든 숫자는 클릭하면 그 숫자의 목록으로(필터 적용된 URL)

불러오기

  • 열릴 때 1회: GET /api/dashboard?preset=sales — 지금 위젯 19개가 각자 쏘는 조회를 서버에서 한 번에(1분 캐시)
  • 프리셋 전환 1회
  • 숫자줄은 먼저 그리고 위젯은 도착 순서대로(스트리밍 아님, 한 응답)
